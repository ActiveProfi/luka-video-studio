# Luka — студия видеоуроков и коротких роликов

## Текущая сохранённая версия — 31 октября 2026

Метка зафиксированной версии: `current-2026-10-31`. [Состав и ограничения текущей версии](docs/CURRENT_VERSION_2026-10-31.md).

[Описание предыдущей версии от 14 октября](docs/CURRENT_VERSION_2026-10-14.md).
[Ошибки и их решения на 14 октября 2026 года](docs/ERRORS_AND_SOLUTIONS_2026-10-14.md).

Локальное приложение для превращения записи экрана с речью автора в видеоинструкцию.
Исходная запись сохраняется; заменяется звук, добавляются субтитры, аннотации и заставки.
Для новых проектов доступна любая тематика с собственным контекстом и терминами.
Существующие уроки 1С сохраняют прежний специализированный профиль.

В готовом проекте появился раздел «Короткие видео из этого урока»:

- ИИ выбирает законченные фрагменты по границам фраз.
- Полезный фрагмент повторно использует готовую озвучку и аннотации.
- Рекламная версия получает отдельный сценарий, проверку утверждений по исходнику
  и отдельную озвучку выбранным голосом.
- YouTube Shorts, Reels и VK Клипы имеют отдельные сценарии и редакционные профили; формат экспорта
  1080 × 1920, 30 кадров/с, H.264/AAC. Это консервативный шаблон до 54 секунд,
  а не заявление о максимальной длительности, допускаемой площадками.
- Экран вписывается целиком. Заголовок, субтитры и призыв находятся вне изображения.
  Мелкие детали широких интерфейсов могут требовать отдельной режиссуры/увеличения.
- Файлы хранятся в `output/<job>/derivatives/<clip>/`. Правки короткого ролика не
  изменяют основной урок. Для другой площадки создаётся отдельный вариант; повторная выдача готовой версии использует сохранённый файл;
  правка заголовка повторно использует рекламную аудиодорожку.
- Публикация в аккаунты не подключена: приложение отдаёт MP4 для скачивания.

Устойчивость: JSON сохраняются через временный файл и атомарную замену; параллельные
изменения проекта сериализуются; работающий этап не считается завершённым по промежуточному
файлу. После перезапуска незавершённая обработка помечается как прерванная, готовые файлы
сохраняются. Автоматического возобновления после отключения питания пока нет.
Сервер предназначен для локального запуска одним процессом, без `--workers` и `--reload`.

Запуск установленной версии из корня проекта:

```powershell
.venv\Scripts\python.exe -m uvicorn src.api.app:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/`. После изменения интерфейса выполните
`npm.cmd --prefix review-ui run build`. Ключи хранятся в локальном `.env`.
Для проверки: `.venv\Scripts\python.exe -m pytest tests/unit -q`.
Историческая документация ниже относится к ранним версиям конвейера.

Конвейер: `raw_video.mp4` → `final_lesson.mp4`

## Быстрый старт

### Шаг 1. Python-окружение (Windows)

> **Важно:** команда `python` у вас ведёт в Microsoft Store и не работает.  
> Используйте **`py -3.13`** — это правильный Python на вашем компьютере.

```powershell
cd "C:\Users\admin\Desktop\АктивПрофи\GROWPILOT AI Студия\Автоматизация своя\Cursor\Автоматизация 1С инструкций"

# Шаг 1. Создать виртуальное окружение (один раз)
py -3.13 -m venv .venv

# Шаг 2. Активировать окружение
.\.venv\Scripts\Activate.ps1

# Если активация блокируется — выполните один раз:
# Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

# Шаг 3. Установить зависимости
python -m pip install -e ".[dev]"
```

**Без активации** (тоже работает):

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest
```

### Шаг 2. Настройка `.env`

```powershell
copy .env.example .env
```

Заполните в `.env` (значения из Yandex Cloud, **не в коде**):

- `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` — для STT и TTS
- `YANDEX_GPT_API_KEY` и `YANDEX_GPT_FOLDER_ID` — для очистки речи
- `OPENAI_API_KEY` — резервный STT/TTS/LLM

### Шаг 3. Тестовые видео

Скопируйте в `fixtures/`:

- `raw_video.mp4` — сырое видео
- `reference_final.mp4` — готовый образец

### Шаг 4. Запуск pipeline (Этап 0)

```powershell
.\.venv\Scripts\python.exe -m src.orchestrator.run_pipeline --input fixtures/raw_video.mp4 --reference fixtures/reference_final.mp4
```

### Шаг 5. API + веб-согласование

**Самый простой способ — одна команда** (откроет 2 окна PowerShell и браузер):

```powershell
.\scripts\start-review-ui.ps1
```

**Или вручную — два терминала:**

Терминал 1 — backend:

```powershell
.\.venv\Scripts\python.exe -m uvicorn src.api.app:app --host 127.0.0.1 --port 8000
```

Терминал 2 — review UI (сначала один раз: `cd review-ui` → `npm install`):

```powershell
cd review-ui
npm run dev
```

Откройте в браузере: **http://127.0.0.1:5173**

> Интерфейс не откроется сам, если не запущены оба сервера (8000 и 5173).

### Шаг 6. Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check src tests
```
