## Известные ограничения

Сценарий основного урока сейчас создаётся из речи автора. В проверенном исходнике
от 15 октября аудиодорожка присутствовала, но локальный детектор не нашёл речевых
участков, включая проверку после усиления. Обработка остановилась до вызова OpenAI.
Сообщение «все STT-провайдеры недоступны» в этом случае неточно; это поведение
сохранено в данном снимке. Генерация полноценного сценария только по экрану без
речи не реализована.

Другие известные ограничения перечислены в
[хронологии ошибок от 15 октября](ХРОНОЛОГИЯ_ОШИБОК_2026-10-15.md).
Приложение рассчитано на локальный запуск одним процессом.

## Запуск из копии репозитория

Требуются Python 3.11+ (использовался Python 3.13), Node.js с npm и FFmpeg/ffprobe.
В корне проекта:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,stt-local,audio,annotations,annotations-ocr]"
npm.cmd --prefix review-ui ci
npm.cmd --prefix review-ui run build
npm.cmd --prefix motion-renderer ci
Copy-Item .env.example .env
```

Заполните `.env` собственными ключами подключаемых сервисов; при необходимости
задайте `FFMPEG_PATH` и `FFPROBE_PATH`. Для OCR через pytesseract нужен отдельно
установленный Tesseract с языками используемых записей.

```powershell
.\.venv\Scripts\python.exe -m uvicorn src.api.app:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000/`.
