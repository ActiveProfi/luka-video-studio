# Как сейчас работают шаги пайплайна (зафиксировано)

Документ описывает **текущее** поведение интерфейса и бэкенда на момент фиксации.  
Нумерация шагов — как в веб-интерфейсе (`order + 1`).

Интерфейс: `http://127.0.0.1:8000`

---

## Общая схема

```
Видео → Распознавание → Speech Script (правка) → Озвучка → Монтаж → Субтитры
         (шаг 1)         (шаг 2)              (шаг 3)              (шаг 4)   (шаг 5)   (шаг 6)
```

Дальше в системе ещё есть шаги 7–8 (аннотации и финальная сборка) — кратко в конце.

**Важно:** исходные паузы в видео **не вырезаются**. Текст и озвучка подгоняются под тайм-слоты видео.

---

## Шаг 1. Загрузка видео

**Что делает**
- Принимает файл видео (и опционально эталон).
- Создаёт задание (`job_id`) и папку артефактов.
- Сохраняет `raw_video.mp4` и `input_manifest.json`.

**Что видите в UI**
- Превью загруженного ролика.
- Можно нажать «Выполнить заново» → вернуться к форме загрузки.

**Результат**
- Видео принято, можно переходить к распознаванию.

---

## Шаг 2. Распознавание речи (STT)

**Что делает**
- Распознаёт речь с таймкодами.
- Сейчас в работе обычно **faster-whisper medium** (локально), с запасными вариантами по настройкам `.env` (`STT_PROVIDER`, `STT_FALLBACK_ORDER`).

**Что видите в UI**
- Краткий текст / JSON распознавания.
- Файл: `transcript.json`.

**Результат**
- Сырой текст урока с привязкой ко времени.

---

## Шаг 3. Подготовка сценария озвучки (Speech Script)

Это главный ручной этап. Состоит из **трёх подшагов**.

Файл для субтитров `clean_transcript.json` **не портится** правками Speech Script.  
Озвучка читает **`speech_script.json`** (текст «после»).

### Подшаг 3.1 — подготовка к озвучке

**Что делает (без кардинальной переписки ИИ)**
- убирает речевой мусор («э-э», «ну» и т.п.);
- правит термины по правилам учёта;
- нормализует под TTS: аббревиатуры в произносимую форму  
  (например, НДС → «эн дэ эс», 1С → «один эс»).

**Не делает:** не переписывает стиль и смысл «с нуля» через LLM.

**Запуск:** автоматически при входе на этап (можно «Запустить 3.1 заново»).

### Подшаг 3.2 — ИИ-помощник по таймингу

**Что делает**
- Подгоняет уже готовый Speech Script **под длительность видео** (бюджет шагов).
- Должен сохранять формат озвучки (расшифровки аббревиатур).
- Не должен дописывать новые предложения «от себя» в конце.
- Если ответ ИИ слишком далеко от Speech Script — отбрасывается.

**Запуск:** **только по кнопке** (не автоматом), чтобы сначала можно было поправить текст вручную.

### Подшаг 3.3 — ручное редактирование

**Что делает пользователь**
- Правит текст в обычном поле (без «залипающей» подсветки и без сетки по символам).
- Можно исправлять ошибки STT, например:  
  `С 2026 годаа н ОС` → `с 2026 года на УСН`.
- **Сохранить** — пишет `speech_script.json` (текст после).
- **Подтвердить и запустить озвучку** — утверждает текст и запускает следующие этапы.

**Правило:** ручной ввод не должен сбрасываться при обновлении данных с сервера, пока вы не сохранили / не запустили ИИ-шаг заново.

---

## Шаг 4. AI-озвучка (TTS)

**Что делает**
- Берёт утверждённый Speech Script (`speech_script.json`, поле текста после).
- Синтезирует речь по тайм-блокам исходного видео.
- Собирает `voiceover.wav` и `voiceover_segments.json`.

**Провайдер:** по `.env` (`TTS_PROVIDER`, обычно Yandex, с запасными вариантами).

**Результат**
- Готовая дорожка озвучки под длину ролика.

---

## Шаг 5. Монтаж видео

**Что делает**
- Накладывает AI-озвучку на исходное видео **с сохранением пауз**.
- Не вырезает паузы из картинки.

**Результат**
- `edited_video.mp4` + отчёт монтажа.

---

## Шаг 6. Субтитры

**Что делает**
- Строит субтитры по таймингу (источник смысла — очищенный транскрипт / связанные артефакты).
- В UI можно менять положение и размер блока субтитров.

**Результат**
- `subtitles.srt`, `subtitle_timing.json`, `subtitle_layout.json`.
- Превью поверх смонтированного видео.

### Подшаг 6.1 — финальная AI-озвучка

**Что делает**
- Берёт текст из блоков субтитров (как на шаге 6) и озвучивает каждый блок в его тайминге.
- Обновляет `voiceover.wav` / `voiceover_segments.json` и пересобирает `edited_video.mp4` с новой озвучкой.

**Запуск:** кнопка «Запустить 6.1» внизу шага 6 (после сохранения субтитров).

---

## Шаг 7. Аннотации (студия)

**Как пользоваться**

1. Откройте задание на этапе «Аннотации».
2. Запустите видео → на нужном кадре нажмите **Pause**.
3. Выберите инструмент **Рамка** или **Стрелка** → нарисуйте на видео.
4. На **дорожке** снизу потяните края блока (по умолчанию ~3 сек, минимум ~0.8 сек).
5. Нажмите **Сохранить аннотации**, затем **Подтвердить аннотации**.

**Результат:** координаты и тайминг в `annotation_suggestions.json`, превью `annotation_preview.mp4`.

## Какие файлы за что отвечают (шаги 1–6)

| Файл | Зачем |
|------|--------|
| `raw_video.mp4` | Исходное видео |
| `transcript.json` | Сырое распознавание |
| `clean_transcript.json` | Текст для субтитров/архива (не ломаем правками Speech Script) |
| `speech_script.json` | Сценарий для озвучки (`text_before` / `text_after`) |
| `tts_preparation_report.json` | Отчёт подготовки к TTS (шаг 3.1) |
| `cleanup_review.json` | Статус согласования текста |
| `voiceover.wav` | Озвучка |
| `edited_video.mp4` | Видео после монтажа |
| `subtitles.srt` | Субтитры |

---

## Как пользоваться шагом 3 на практике

1. Дождаться конца шага 2 (распознавание).  
2. На шаге 3 дождаться **3.1** (подготовка к озвучке).  
3. При необходимости поправить текст в поле (**3.3**).  
4. При необходимости нажать **3.2** (подгонка тайминга).  
5. Снова проверить текст глазами.  
6. **Сохранить** → **Подтвердить и запустить озвучку**.
