# Рекламный монтаж из видеоурока

Изучен соседний проект «Ремоушн»: `src/ads/activprofi/RevenueTight.tsx`,
`src/variants/kinetic/KineticScene.tsx`, `src/video/SemanticVideo.tsx`,
`docs/architecture/LIBRARY_TRANSFER.md` и текущее состояние проекта.
Его исходники, результаты и настройки не изменялись.

Перенесены принципы, а не готовое содержание чужого ролика:

- сцены с отдельными входом, действием и временем для чтения;
- смена кадра по смыслу озвучки, сохранённое объяснение выбора;
- кинетический заголовок, контрастные акценты и состояние до/после;
- подтверждённые координаты объектов вместо выдуманного интерфейса;
- техническая проверка не заменяет просмотр результата.

Реализация находится в `motion-renderer`, независимо от соседнего проекта.
Установка: Node.js, `cd motion-renderer`, `npm ci`.
Remotion использует собственный Chrome Headless Shell; при первом запуске
загружает его. При необходимости `REMOTION_BROWSER_EXECUTABLE` задаёт путь
к совместимому локальному браузеру. Проверка TypeScript: `npm run check`.

В рекламной версии `semantic-shots.json` связывает каждую фразу с фрагментом
полного урока, короткой цитатой и необязательным подтверждённым выделением.
Планировщик передаёт в настроенную LLM тексты и подписи объектов, не видео.
`motion-plan.json` содержит фактические границы сцен после ускорения 1,2×,
откуда взяты кадры и почему. Фрагменты исходного видео локально подгоняются
под длину реплик. Основной урок и его сценарий не изменяются.

Визуальная версия: фиолетовый, лаймовый и коралловый акценты, крупные цитаты,
анимированная рамка с реальным экраном, приближения подтверждённых объектов,
посценовые субтитры короткими группами и финальный призыв. Заголовки — цитаты
из рекламы, а не новые обещания. Выделение активно только в проверенном
временном интервале исходного видео. Не используется генерация новых экранов.

Субтитры привязаны к измеренным границам реплик. Внутри реплики группы текста
распределяются расчётно; это не покадровое распознавание каждого слова.
Выбор фрагментов по тексту может требовать редакторского улучшения:
он не доказывает визуальную релевантность каждой детали. Кадры каждой сцены
сохраняются для визуальной проверки. MP4 — полный экспорт 1080×1920;
WebM — совместимый облегчённый предпросмотр в приложении.

Рекламная озвучка синтезируется одним связным абзацем: одинаковые паузы
между отдельно озвученными предложениями больше не добавляются. Внутренние
паузы сохраняются такими, как их сформировал голос по пунктуации и контексту.
Локальный Whisper измеряет границы предложений в полученном звуке; сцены
перестраиваются по этим границам с сохранением скорости 1,2×. Если надёжное
сопоставление не получилось, экспорт сообщает ошибку, не выдумывая тайминги.
`connected_voice.json` кэширует абзац, а `prosody-report.json` содержит
измеренные интервалы. Неудачное измерение можно повторить без нового TTS.
Естественность тембра и интонации по-прежнему зависит от выбранного голоса.
