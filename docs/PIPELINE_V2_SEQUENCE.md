## Целевая схема

1. Загрузка видео  
2. Распознавание речи  
3. Подготовка сценария — фокус на **3.2 ИИ-подгонка тайминга**  
4. Разбивка на блоки / редактирование субтитров (**до** озвучки)  
5. Текст для озвучки (Speech Script) — **два окна**, утверждение по частям  
6. Финальная озвучка (бывший подшаг 6.1)  
7. Аннотации  
8. Сборка урока
