# Тестовые видео

Положите сюда два файла (они **не попадают в git** — см. `.gitignore`):

| Файл | Назначение |
|------|------------|
| `raw_video.mp4` | Сырой исходник — **вход** pipeline |
| `reference_final.mp4` | Уже обработанный урок — **образец**, к которому стремимся |

## Текущие файлы (2026-06-16)

| Файл в `fixtures/` | Исходное имя |
|--------------------|--------------|
| `raw_video.mp4` (~137 МБ) | `1 урок определение месяца применения НДС (исходник) .mp4` |
| `reference_final.mp4` (~52 МБ) | `1 урок ... (смотреть после обработки) .mp4` — образец готового урока |

Оригиналы остаются в корне проекта.

## Шаг 2. Проверка

После копирования запустите:

```powershell
python -m src.orchestrator.run_pipeline --input fixtures/raw_video.mp4 --reference fixtures/reference_final.mp4
```

Pipeline сохранит путь к образцу в `input_manifest.json` для сравнения на этапе QA.
